# StayEase - Hotel & Property Booking Web Application

StayEase is a full-stack web application designed to help users discover, explore, and inquire about premier properties and hotels across Sri Lanka. 

### Key Features
* **Property Showcase:** Dynamic catalog displaying high-res image galleries, amenities, rates, and location details.
* **Booking Inquiries:** Direct reservation inquiry system handling guest check-in/check-out dates and guest counts.
* **Interactive Reviews & Ratings:** Real-time guest review submission system with custom criteria (Cleanliness, Location, Service).
* **AI Assistance:** Built-in AI chatbot to help users with instant property recommendations, booking assistance, and local travel tips.
* **Database Management:** Database seeding scripts for instant deployment of sample listings.

### Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Inter Font, Responsive Design
* **Backend:** Node.js, Express.js, CORS
* **AI & API Integration:** OpenAI API / Google Gemini API (or your chosen AI service)
* **Database:** MongoDB Atlas Cloud, Mongoose ODM
